# Test fonts

`twemoji-subset.ttf`, `.woff` and `.woff2` are one font in three containers: six emoji (😀 ❤️ ✅ 🚀 🌈 👍🏽) cut from [Twemoji Mozilla](https://github.com/mozilla/twemoji-colr) v0.7.0 with fontTools' `pyftsubset`. Nothing else was changed.
